# Youthink Europe
> Youthink Europe is a project founded in Europe, dedicated to youth. Find volunteering, Model UN, youth councils, internships and fellowships around the world. Build a profile of your civic experience, and connect with organizations that share your values.

**Who is it for?**
> - **Young people (13-30)** looking for volunteering, MUN conferences, youth councils, workshops, and fellowships
> - **Organizations** such as NGOs, MUN organizers, councils, and school clubs that want to reach motivated young people
> - **Anyone** who believes youth should have a seat at the table

> [!NOTE]
> Youthink is **in early development**. The first version is being built right now, and a private beta is planned. Want to be among the first to try it? Follow the project and watch this repository for updates.

**Contribute**
> While we don't accept contributions to the Youthink project from members outside of Youthink, we encourage you to fork the project and make it your own!
